One haiku about debugging in the 5-7-5 syllable shape, written deterministically to `/output/entry.txt`: a cursor blinking at 3am, a stack trace ending in silence, and the turn — it was a comma. No input, no clock, no network; the same bytes on every run.

## Run it

```sh
node main.ts
```

Needs Node 22.18 or later (TypeScript runs as-is).
